# 模力枢纽 · Model Route Hub

**发现模型，验证方案，连接算力。**

模力枢纽是面向开发者的中文 AI 模型与算力资源导航。你可以在一个工作台中查找模型 API、GPU / CPU 服务和 Token 工具，试问真实模型，生成接入配置，并估算使用成本。网站无需注册。

[进入工作台 ↗](https://model-route-hub-chen-20261016.nutty-wren-8644.chatgpt.site/) · [体验模型](https://model-route-hub-chen-20261016.nutty-wren-8644.chatgpt.site/#free-lab) · [阅读选型指南](https://model-route-hub-chen-20261016.nutty-wren-8644.chatgpt.site/guides/choose-api-gpu-cpu.html)

## 可以做什么

| 功能 | 说明 |
| --- | --- |
| 资源目录 | 浏览 27 项模型 API、GPU、CPU 和 Token 资源；按类别筛选、搜索、收藏，并前往服务商官方文档。 |
| 浏览器本地模型 | 在支持 WebGPU 的设备上运行 Qwen2.5 0.5B、1.5B 或 Coder 1.5B。回答在本机生成，无需登录，本站不限制本地试问次数。 |
| 限量云端试问 | 选择当前可用的免费模型，在本站直接提问。由本站承担有限额度，每位访客最多两次；问题会发送给模型服务方。 |
| 接入与估算 | 生成 Python、JavaScript、cURL、PowerShell 接入示例，并粗估 Token 费用、提示词长度和模型权重显存。 |

目前收录 **27 项资源**：13 个模型 API、6 个 GPU 服务、4 个 CPU 服务、4 个 Token 工具。资源数量截至 2026-10-16；价格、免费额度和可用地区请以服务商官方页面为准。

## 开始使用

1. 打开[资源目录](https://model-route-hub-chen-20261016.nutty-wren-8644.chatgpt.site/#catalog)，按任务选择模型 API、GPU 或 CPU。
2. 到[免费体验区](https://model-route-hub-chen-20261016.nutty-wren-8644.chatgpt.site/#free-lab)选择本地或云端试问。首次运行本地模型需下载数百 MB 文件，并要求浏览器支持 WebGPU；云端免费型号可能限流或暂停。
3. 在[路由配置生成器](https://model-route-hub-chen-20261016.nutty-wren-8644.chatgpt.site/#builder)创建接入示例。API Key 由你自行保管，本站不收集或代发付费 API 请求。

## 收录与反馈

优先收录有官方文档、清晰入口和可核对服务条件的资源。欢迎通过 [GitHub Issues](https://github.com/notquitezero-ai/model-route-hub/issues/new) 推荐资源、报告失效链接或提出合作建议；请附官方来源，不要提交 API Key 或保密报价。

本仓库用于项目介绍与公开反馈。模力枢纽是独立资源索引：目录链接目前不是专属返佣链接，与所列服务商没有合作关系；本站不销售 Token 或算力，也不代收服务商费用。
